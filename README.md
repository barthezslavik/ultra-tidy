# Ultra Tidy

Нативное приложение для macOS, которое читает медиатеку Photos и показывает группы похожих фотографий. Интерфейс и доступ к Фото используют системные SwiftUI и PhotoKit; вычисление визуальных признаков и группировка выполняются библиотекой на Rust. Медиатека не изменяется.

## Сборка

Требуются macOS 14+, Xcode Command Line Tools и Rust.

```sh
./build-app.sh
open "dist/Ultra Tidy.app"
```

При первом запуске разрешите доступ к Фото и нажмите «Сканировать». При ограниченном доступе приложение обработает только выбранные фотографии. Фотографии, недоступные локально или через iCloud, будут пропущены.

Выберите группу слева и просмотрите крупные миниатюры. Сведите или разведите два пальца на трекпаде над сеткой, чтобы изменить масштаб; ползунок над сеткой делает то же самое. Щелчок по миниатюре отмечает снимок для удаления или снимает отметку. Кнопка «Удалить отмеченные» отправляет все отмеченные снимки на удаление одной операцией, поэтому Photos показывает одно системное подтверждение для всего набора. После удаления список групп обновляется.

Сходство определяется по разнице яркости на уменьшенном изображении и среднему цвету. Если снимки сделаны в течение часа, алгоритм допускает чуть больше визуальных отличий. Очень похожие фото объединяются независимо от даты; при отсутствии даты используется только визуальное сходство. Сильно обрезанные или отредактированные версии могут не попасть в одну группу.
